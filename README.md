# 📊 Organizador de Declaração de Imposto de Renda no Excel

Este repositório contém o projeto de um agregador e organizador de dados fiscais desenvolvido inteiramente no Microsoft Excel. O objetivo principal da ferramenta é centralizar, validar e estruturar todas as informações necessárias para facilitar o preenchimento da Declaração de Imposto de Renda (IRPF).

## 🚀 Funcionalidades da Ferramenta
- **Agregação Base de Dados:** Centralização de informes de rendimentos, recibos médicos, despesas dedutíveis e controle de bens.
- **Validação de Dados:** Menus suspensos inteligentes que blindam a planilha contra erros manuais de digitação.
- **Navegação Facilitada:** Criação de um menu interativo (Dashboard) com botões e hiperlinks internos para alternar entre as abas de notas fiscais, dependentes e fontes pagadoras.
- **Interface Amigável:** Layout limpo e profissional focado na usabilidade de usuários comuns.

## 🛠️ Recursos Técnicos Aplicados
- Fórmulas de busca, referência e tratamento de texto.
- Estruturação de tabelas inteligentes e formatação condicional de prazos/metas.
- Criação de links rápidos de navegação e botões interativos no painel inicial.

## 📁 Como Utilizar
1. Faça o download do arquivo `.xlsx` disponível neste repositório.
2. Abra o arquivo no Microsoft Excel.
3. Utilize os botões do painel principal para navegar até as seções desejadas e preencher suas informações fiscais com total controle.
